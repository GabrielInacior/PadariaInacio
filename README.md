## 🚀 **COMO EXECUTAR**

### **1. Instalação:**
```bash
cd PadariaInacio
npm install
npx expo install
```

### **2. Executar:**
```bash
# iOS
npx expo run:ios

# Android
npx expo run:android

# Web
npx expo start --web
```

### **3. Build:**
```bash
# Build de produção
npx expo build:android
npx expo build:ios
```
